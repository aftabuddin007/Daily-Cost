Daily Cost Tracker Website

A simple and user-friendly Daily Cost Tracker Website built with HTML, CSS, and JavaScript. This project helps users record, manage, and analyze their daily expenses efficiently.


---

📌 Project Overview

The Daily Cost Tracker is a lightweight web application designed to help users keep track of their everyday spending. It allows users to add expenses, categorize costs, view spending history, and monitor their financial habits.

This project is fully frontend-based and works directly in the browser without requiring a backend server.


---

🚀 Features

Add daily expenses easily

Edit or delete expense records

Categorize expenses

View total spending

Responsive and clean user interface

Fast and lightweight

Beginner-friendly project structure

Real-time expense updates using JavaScript



---

🛠️ Technologies Used
